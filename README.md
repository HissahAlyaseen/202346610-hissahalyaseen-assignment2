# Hissah Alyaseen Portfolio

## Project Description

This project is a responsive personal portfolio website built using HTML, CSS, and JavaScript.

The website includes an About Me section, Projects, a Contact form, responsive design, and a JavaScript greeting feature.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Technologies Used

- HTML
- CSS
- JavaScript
