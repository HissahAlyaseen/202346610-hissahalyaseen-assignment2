# Hissah Alyaseen Portfolio - Assignment 2

## Project Description

This project is an interactive personal portfolio website built using HTML, CSS, and JavaScript.

It is an improved version of Assignment 1 and includes dynamic project details, form validation, user feedback, responsive design, and simple animations.

## Features

- About Me section
- Projects section with interactive Show Details / Hide Details buttons
- Contact form with input validation
- Success and error messages for the contact form
- Responsive design for desktop, tablet, and mobile
- Hover animation on project cards
- Greeting message based on the time of day

## Projects

### Hello Web App

A simple web application built using Node.js and Express. It helped me practice basic web development concepts and server-side development.

### Recipe Sharing Platform

An in-progress recipe-sharing platform designed for users with dietary restrictions such as halal, vegan, gluten-free, and food allergies.

2. Open the project folder.
3. Open `index.html` in a web browser.
4. Test the project buttons and contact form.
