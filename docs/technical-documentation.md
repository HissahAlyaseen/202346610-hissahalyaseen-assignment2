# Technical Documentation

## Tools Used & Use Cases

I used ChatGPT during this assignment to help me understand HTML, CSS, and JavaScript concepts.

I used it to:
- Explain the structure of HTML elements such as sections, navigation, forms, and project cards.
- Help organize and style the portfolio using CSS Flexbox and Grid.
- Debug issues related to linking CSS and JavaScript files.
- Add responsive design for smaller screens.
- Create a JavaScript greeting message based on the time of day.

## Benefits & Challenges

Using AI helped me understand the purpose of different HTML and CSS properties instead of only copying code.

One challenge was that some suggested code did not work immediately because of incorrect file locations or linking paths. I had to check the project structure and test the files again.

## Learning Outcomes

I learned how HTML, CSS, and JavaScript work together in a web application.

I also learned how to:
- Link external CSS and JavaScript files.
- Use Flexbox and Grid for page layout.
- Create responsive designs using media queries.
- Use JavaScript to add simple interaction to a webpage.
- Debug problems related to file paths.

## Responsible Use & Modifications

I reviewed the AI-generated suggestions before adding them to my project.

I asked for explanations when I did not understand parts of the code and modified the code to match my own portfolio content and project ideas.

I also tested the website after each major change to make sure the code worked correctly.
